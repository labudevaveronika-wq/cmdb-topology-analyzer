# CMDB & Network Topology Impact Analyzer

Система учета конфигурационных единиц (CMDB) и анализа топологии сетевых зависимостей с поддержкой REST API и визуализацией через Graphviz.

## Основные возможности
- **Учет конфигурационных единиц (КЕ):** хранение серверов, баз данных и сервисов, их IP-адресов и статусов в PostgreSQL.
- **Анализ взаимодействий:** поиск входящих (Inbound) и исходящих (Outbound) зависимостей узла за $O(1)$, выявление изолированных серверов.
- **Оценка зоны риска (Impact Analysis):** каскадный расчет затронутых систем при отказе узла с помощью обхода графа в ширину (BFS) за $O(V + E)$.
- **Импорт/экспорт JSON:** массовая загрузка и выгрузка топологии инфраструктуры.
- **REST API с авторизацией по токену:** фоновый HTTP-сервер для интеграции с внешними системами мониторинга.
- **Визуализация:** автоматическая генерация схемы инфраструктуры (`topology.png`) через Graphviz.

## Стек технологий
- **Язык:** C++17
- **Сборка:** CMake
- **СУБД:** PostgreSQL (`libpqxx`)
- **Библиотеки:** `nlohmann/json`, `cpp-httplib`
- **Визуализация:** Graphviz
